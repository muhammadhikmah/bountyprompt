# AI Bug Bounty Prompts

A curated collection of prompts designed to guide AI in performing bug bounty tasks, vulnerability analysis, and security assessments efficiently.

## Overview

This repository contains prompts that help AI assist in:

- **Source code review** for security issues
- **Web application vulnerability identification**
- **Exploit development guidance**
- **Reconnaissance and enumeration tasks**

## Usage

1. Browse the prompts in their respective folders.
2. Copy the prompt text.
3. Use it with your preferred AI tool (e.g., ChatGPT) to guide security testing tasks.
